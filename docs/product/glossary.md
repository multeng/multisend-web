# Словарь без предварительных знаний

Рабочая редакция 09.11.2026. [Функции](README.md) · [Вопросы и ответы](faq.md).

| Слово в приложении                   | Что это значит                                                                                                                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| TON                                  | Сеть для учёта переводов и её основная монета. В текущем приложении используется тестовая сеть                                                                                 |
| Testnet                              | Отдельная сеть для испытаний. Её тестовые TON не являются TON основной сети; не покупайте реальные монеты ради наших текущих тестов                                            |
| Mainnet                              | Основная сеть, где операции имеют реальную денежную стоимость. Пока не поддерживается приложением                                                                              |
| Кошелёк                              | Приложение, например Tonhub, через которое пользователь управляет адресами и подтверждает действия                                                                             |
| Адрес                                | Строка назначения перевода. Правильный формат не доказывает, что адрес принадлежит нужному человеку                                                                            |
| TON Connect                          | Способ связи сайта с приложением кошелька. Не передаёт сайту секретную фразу пользователя                                                                                      |
| Подключение                          | Установка связи с кошельком. Само по себе не означает завершённый вход на сервере                                                                                              |
| Подпись входа                        | Подтверждение кошельком, что вы управляете адресом. В нашем сценарии не является переводом средств                                                                             |
| Seed / секретная фраза / private key | Секреты, позволяющие управлять средствами. TON Multisend не просит их вводить; в поддержку их тоже не отправляют                                                               |
| Черновик                             | Сохранённый список адресов, сумм и комментариев. Сохранение не отправляет деньги                                                                                               |
| CSV / TSV                            | Текстовый табличный файл: строки получателей и поля, разделённые выбранным символом. Подробности — в [инструкции](../csv-format.md)                                            |
| Нанотон                              | Одна миллиардная TON: 0.000000001 TON. Девять знаков после точки позволяют указать сумму точно                                                                                 |
| Контракт кошелька                    | Программа аккаунта в сети. Наличие приложения кошелька на телефоне не означает, что эта программа уже развёрнута в сети                                                        |
| UNINIT                               | На адресе могут быть средства, но контракт ещё не развёрнут. Текущая оценка расходов такой аккаунт не поддерживает                                                             |
| ACTIVE                               | Контракт аккаунта развёрнут. Для оценки также нужна поддерживаемая версия V4R2 и допустимый лимит сообщений                                                                    |
| V4R2                                 | Конкретная версия программы кошелька, которую сейчас поддерживает наш расчёт. Название Tonhub само по себе версию контракта не определяет                                      |
| Сообщение                            | Действие, передаваемое между контрактами TON. В нашем плане одна строка получателя создаёт отдельное сообщение                                                                 |
| Часть / запрос подписи               | Группа строк по лимиту кошелька. Сейчас это только план; будущую отправку каждой части потребуется подтверждать отдельно                                                       |
| Сетевая комиссия                     | Расход на обработку операции сетью. Оценка может отличаться от фактических расходов будущего перевода                                                                          |
| Комиссия сервиса                     | Плата самому сервису. Сейчас в testnet — 0 TON; сетевая стоимость от этого не исчезает                                                                                         |
| Резерв native-v1                     | Временный запас в требуемом балансе: минимум 0.01 TON или 20% сетевой оценки, если они больше. Не блокирует и не списывает деньги                                              |
| Дефицит                              | Разница, которой не хватает до требуемого баланса с учётом оценки и резерва                                                                                                    |
| Bounce                               | Настройка возврата сообщения при определённых ошибках обработки получателем. Возврат не гарантирован, расходы возможны; это не отмена отправки и не защита от неверного адреса |
| Блок / снимок баланса                | Состояние сети на определённый момент. После него баланс может измениться                                                                                                      |
| Срок оценки                          | Время, после которого оценкой нельзя пользоваться как актуальной. Текущий срок не более 30 секунд; затем нужен новый расчёт                                                    |
| Конфликт версий                      | Черновик уже изменили в другом окне или устройстве. Новая запись не должна молча затереть эти изменения                                                                        |
| Web app / PWA                        | Сайт, который можно добавить на главный экран и запускать отдельным окном. Установка не означает работу без интернета или публикацию в App Store/Google Play                   |
